# 2026 3Q Townhall face-card game (archived bundle)

This folder preserves the publicly served JavaScript and CSS from the original 2026 3Q Townhall game at https://kearney-2026-3q-townhall-game.web.app/. The face-card matching game is included in `app.js`: players flip two cards to find matching faces and answer a name quiz.

These are the original deployed, minified assets, not the original development source. The JavaScript bundle also contains the rest of the Townhall application and third-party dependencies. Its embedded license notices have been retained. A source map was not available.

This is a code archive, not a self-contained runnable app. HTML, Firebase configuration, database contents, uploaded photographs, and credentials are not included. The original application expects a `/firebase-config.json` and a backend; running it against the original configuration could access or alter live data. To rebuild or deploy it, use an independent backend and supply your own configuration and assets.
